# 漢堡疊疊樂 🍔

左右移動底盤，接住跌落嘅材料，對齊疊出完美漢堡。

## 點玩
1. 用瀏覽器打開 `index.html`（毋須安裝／build）
2. 點「開始疊漢堡」
3. 拖曳或用方向鍵 ← → 移動底盤，接住由上跌落嘅材料
4. 疊到頂包就完場；對齊太差會散枱

## 評分標準
落地時以水平重疊％計分：完美置中加分，突出部分會削窄下一層寬度；重疊低於 18% 即散枱出局。

## 點分享
完場後撳「下載結果圖」儲存直向結果卡，再上傳 Threads 挑戰朋友。

## 點開
直接雙擊或：
```bash
open index.html
# 或 python3 -m http.server 8080 後開 http://localhost:8080
```
