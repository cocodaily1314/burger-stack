# 漢堡疊疊樂 🍔

左右移動底盤，靠眼力接住跌落嘅材料，限時疊出完美漢堡。每局材料池會洗牌，偶爾仲有野味料。

## 點玩
1. 用瀏覽器打開 [GitHub Pages](https://cocodaily1314.github.io/burger-stack/) 或本地 `index.html`（毋須安裝／build）
2. 點「開始疊漢堡」
3. 拖曳、撳左／右半邊，或用方向鍵 ← → 移動底盤
4. **冇度位指示**——全靠眼力對齊；頂部有倒數時間 bar，時間到即完場
5. 疊到頂包就完場；對齊太差會散枱
6. 主廚／傳說廚神頭銜極罕有——速度快、時間緊、評分嚴

## 評分標準
落地時以水平重疊％計分：完美置中加分，突出部分會削窄下一層寬度；重疊低於約 26% 即散枱出局。計分準確，但畫面唔會顯示對齊輔助線。

## 點分享
完場後撳「下載結果圖」儲存直向結果卡（含 Run ID、seed、稀有度、奇怪組合名、廚神簽、時間戳），再上傳 Threads 挑戰朋友。每局結果卡都獨一無二。
