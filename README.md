# 漢堡疊疊樂 🍔

拖曳畫布左右移動底盤，接住跌落嘅材料，**不停疊高**。簡單物理：重心／支撐面、重力加速下落；對齊太差會**倒塌**。畫面用 three.js 立體渲染。

## 點玩
1. 用瀏覽器打開 [GitHub Pages](https://cocodaily1314.github.io/burger-stack/) 或本地 `index.html`（毋須安裝／build；需可連 CDN 載入 three.js）
2. 點「開始疊漢堡」→ 可選 3-2-1 倒數
3. **拖曳畫布**左右移動（無底部 ◀移中▶ 按鈕）
4. **無限層**——唔再以 10 層封頂當勝利；鏡頭跟住高度
5. **冇限時 bar**——玩到倒塌／接唔到為止
6. 冇對齊輔助線；平衡％只係 HUD 回饋

## 物理／評分
落地以重疊接觸面收窄支撐；追蹤重心（COM）。重心偏離底座支撐範圍，或累積傾斜過大 → 物理倒塌。分數睇對齊質素同層數。

## 點分享
完場後撳「下載結果圖」儲存結果卡（含總分、層數、平衡、完美次數、Run ID、時間戳），再分享挑戰朋友。
